# 테스트 경로

에뮬레이터에서 주행 거리를 테스트할 때 재생하는 GPX 경로입니다. 재생 방법은 [README의 테스트 경로 재생](../README.md#테스트-경로-재생)에 있습니다.

| 파일 | 경로 | 거리 | 속도 |
| --- | --- | --- | --- |
| `seoul_drive.gpx` | 서울 시내 | 약 8km | 40km/h (약 12분) |

## 출처

`seoul_drive.gpx`는 [gpx.studio](https://gpx.studio)로 만들었습니다.
